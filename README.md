# smart-personal-task-manager
Web-based personal task manager with due dates, priority filtering, and recurring tasks — Java OOP + JDBC + MySQL

---

## Features

- User Registration and Login
- Dashboard with task summary
- Task Management (Create, Update, Delete)
- Category Management
- Task Priority Management
- Task Reminder Management
- Recurring Task Support
- User Profile Management
- Registered User Directory
- Responsive User Interface

---

## Technologies Used

- Java
- JSP & Servlets
- JDBC
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Apache Tomcat
- Maven
- Git & GitHub
